# Submitted Project information to Raffle

## Submission description

> TrigLoop is a gamified unit-circle learning site for students studying trigonometry. I built it because memorizing a unit-circle chart can feel disconnected from the actual patterns behind sine and cosine. TrigLoop combines an interactive visual explorer with four short game modes that train angle locations, exact trig values, coordinates, and quadrant signs. It includes streaks, combo scoring, XP, levels, animations, sound feedback, and browser-local progress tracking. The entire project is built with HTML, CSS, SVG, and vanilla JavaScript, so it runs as a fast static site and is deployed on GitHub Pages with no backend.
